# Customer Relationship Hub — gratis iPhone-versie

Statische PWA voor gratis hosting via GitHub Pages. De CRM-data worden lokaal op het apparaat opgeslagen in de browser (IndexedDB), inclusief foto's. Er is geen account of server nodig.

## Belangrijk
- Data synchroniseren niet tussen apparaten.
- Verwijderen van websitegegevens/browserdata of verlies van toestel kan data wissen. Gebruik regelmatig de Back-up-functie.
- Bewaar geen gevoelige persoonsgegevens zonder passende beveiligingsmaatregelen.
- Voor iPhone: open de gepubliceerde GitHub Pages-URL in Safari en kies Deel → Zet op beginscherm.

## GitHub Pages
1. Plaats de inhoud van deze map in de hoofdmap van een GitHub-repository.
2. Repository → Settings → Pages.
3. Build and deployment: Deploy from a branch; branch `main`, folder `/(root)`; Save.
4. Wacht tot GitHub Pages de URL toont.
